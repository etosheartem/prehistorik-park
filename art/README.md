# Арт и бюджет

## Исправления полноты 1.0.1

`audit_remake.py` создаёт реестр 499 сравнений и контактные листы, не меняя ресурсы.
`check_remake.py` проверяет размеры и выявленные регрессии; он включён в общую сборку.
`repair_parts.py` возвращает GRR! и размещает разрозненные камни по исходным
компонентам. `install_parts.py` и `install_actors.py` воспроизводят исправленные
ресурсы локально. Исходники генерации и оригинальные изображения не перезаписываются.
Полный отчёт: [docs/qa/remake-1.0.1.md](../docs/qa/remake-1.0.1.md).

## Релиз 1.0: локальная генерация и исправления

Новая портретная заставка создана на RTX 3070 Ti через локальный ComfyUI 0.37.0:
Krea 2 Turbo Q4_0, Qwen3-VL 4B FP8, Qwen Image VAE, seed 2026101301,
10 шагов, 1024×1536. Максимальный вариант 2048×3072 получен локальным
Real-ESRGAN (`realesr-animevideov3`, ×2). Workflow и исходник: `art/local/`.
Дополнительных моделей скачивать не потребовалось. Расход API: **$0**.

```sh
# ComfyUI с указанными моделями должен работать на 127.0.0.1:8188
python art/generate_menu_local.py
```

Скрипт сохраняет задание и путь результата ComfyUI; установленные изображения
уже находятся в `game/assets/hd/ui/`. При воспроизведении сохраняй новый результат
отдельно и сравнивай до замены ресурсов. Модели не нужны для обычной сборки.

`repair_geometry.py` сохраняет 13 структурных деталей горок с точной геометрией
локального апскейла в отдельном пространстве ресурсов ремейка. Новые команды
ремейка привязывают 846 концов канатов к нарисованным деталям с коррекцией не более
4 логических пикселей. Исходные команды JAR не меняются. Земля и площадки рисуются
сплошными полигонами без зелёной сетки. Каталог заново отрендерен из этих слоёв.

Настройки используют отдельный живой парк. Профиль «Баланс» уменьшает загружаемые
текстуры мира вдвое по каждой стороне; три цветовых варианта применяются только
к миру ремейка, не к интерфейсу или оригинальным режимам.

Ниже сохранена история 0.1–0.3; размеры старой заставки, API-бюджеты и названия
beta-режимов относятся к этим версиям, а не к текущей сборке.

## Локальный интерфейс 0.3

Новые рамки, кнопки и иконки рисуются `make_interface.py` в SVG, без API.
Шрифты Noto и их лицензия включены в `game/assets/ui/fonts/`. Новые растровые
иллюстрации не генерировались: главное меню переиспользует имеющиеся заставки.
Оригинальные режимы сохраняют родную заставку с логотипом и орнаменты. Ремейк
использует деревянную вывеску, читабельную типографику и локальный векторный фон.

`game/tests/export_catalog.gd` рендерит объекты настоящими игровыми слоями,
обрезает прозрачные поля и сохраняет 153 небольших превью в `game/assets/ui/catalog/`.
Для экспорта требуется графический backend; скрипт не работает в headless-режиме.

```sh
python art/make_interface.py
python art/make_terrain.py
godot --headless --path game --editor --import --quit
godot --path game --script res://tests/export_catalog.gd
godot --headless --path game --editor --import --quit
bash tools/build_apk.sh
```

Сборка 0.3 и отчёты — `build/prehistorik_park_0.3.apk`, `build/reports_0.3/`.
Графика мира сохраняет исходные команды и фазы; в 0.3 обновлены только палитра
векторной земли, контактные тени и фоновые эффекты. Большие проблемы стыков
аттракционов остаются отдельными пунктами `TODO.md`.

## Режимы графики 0.2 и локальный апскейл

В настройках четыре режима: **Оригинальные**, **Оригинальные · апскейл** (по умолчанию),
**Ремейк · среднее (beta)** и **Ремейк · макс (beta)**. Платные изображения релиза 0.1
используются только в двух beta-режимах. Оригинальные режимы используют исходную графику JAR,
включая оформление меню. Первый режим сохраняет пиксельную фильтрацию, второй — GPU-апскейл ×4.

`upscale_original.py` использует локальный Real-ESRGAN NCNN/Vulkan на RTX 3070 Ti 8 ГБ.
После сравнительного пилота выбраны `realesr-animevideov3` для игровых атласов/шрифта и
`realesrgan-x4plus-anime` для заставок. Две группы обрабатываются параллельно.
Обработаны 40 исходных листов; из них собираются 518 ресурсов и 192 изолированные детали.
Логические размеры, положение опор и исходные команды всех фаз анимации остаются прежними.
Шрифт сначала возвращается из экспортного nearest ×4 к исходным пикселям, затем проходит нейросеть.

Перед обработкой скрытый RGB заполняется цветами ближайших непрозрачных пикселей, чтобы
нейросеть не создавала чёрную кайму. Альфа каждого фрагмента восстанавливается из отдельного
исходного кропа. Mipmaps строятся по изолированным текстурам: соседние части атласа не попадают
в края. PNG и импорт текстур без потерь; оригинальные файлы не перезаписываются.

```sh
python art/upscale_original.py --run       # GPU; готовые проверенные результаты кешируются
python art/upscale_original.py --assemble # сборка кропов из готовых GPU-листов
python art/upscale_original.py --check    # хэши, геометрия, исходники, GPU-журналы
```

Пути к установленному бинарнику и весам можно задать через `PARK_ESRGAN_BIN` и `PARK_ESRGAN_MODELS`.
Результат — `game/assets/upscaled/`; модели, SHA-256, GPU-логи и связи с исходниками —
`art/upscale/report.json` и `art/upscale/runs/`. Для всей переработки 0.2 расход API **$0**.

## Генерация ремейка 0.1

Исходные изображения остаются в `original/jar` и `game/assets/original`. Платные запросы выполняет только `generate.py`; каждый запрос задан JSON-файлом в `jobs/`. По умолчанию скрипт проверяет параметры без обращения к сети. Для отправки конкретного задания требуется `--run`.

```sh
python art/generate.py art/jobs/menu_4k_v1.json
```

Ключ читается только из переменной окружения `OPENROUTER_KEY` и не попадает в исходники, задания и журналы. Запросы не повторяются автоматически. Уже использованный ID и уже существующий результат блокируют повторную оплату. Перед отправкой сумма резервируется в `costs.json` под файловой блокировкой и проверяется доступный баланс аккаунта. Фактический расход берётся из `usage.cost`, неопределённый исход сохраняет резерв до проверки и блокирует новые запросы. Первоначальный пилот ограничивался $1.50; после разрешения пользователя использовать бюджет $10 рабочий предел повышен до **$9.50**, с запасом на отклонение цены. Актуальные суммы всегда находятся в `costs.json`.

Генерация этого релиза завершена: **20 запросов, $8.665693 фактического расхода**, без неопределённых резервов и автоматических повторов. На момент закрытия баланс OpenRouter — **$1.233290**. Итог сохранён в `budget-summary.json`; флаг закрытия в `costs.json` блокирует дальнейшие платные запросы текущего релиза. Один целевой повтор исправил слишком пиксельный стиль двух гостей; первичный результат сохранён в `raw/` для аудита, в игру установлен исправленный вариант.

## Важное ограничение цены Riverflow

Справочник endpoint показывает начальные $0.15/$0.17, но описание модели указывает **динамическую итоговую цену**, зависящую от сложности и внутренних проходов. Именно поэтому пилот стоил $0.390302. Источник: [официальная карточка Riverflow 2.5 Pro](https://openrouter.ai/sourceful/riverflow-v2.5-pro). Фактический расход хранится отдельно от первоначальной оценки.

Для дальнейших запросов установлен резерв минимум $0.80; Riverflow 4K резервирует $1.50. Это локальный запас бюджета, а не жёсткое ограничение стоимости на стороне сервера. Запросы идут последовательно; следующие листы разрешены после проверки цены и сборки анимации из первого листа. В [документации Image API](https://openrouter.ai/docs/guides/overview/multimodal/image-generation) не заявлен параметр максимальной стоимости отдельного изображения; клиент не делает вид, что такой предел существует.

## Повторно используемые детали и персонажи

1209 фаз аттракционов состоят из 106 повторяемых растровых деталей и исходных векторных линий. Оплачены 100 содержательных деталей на семи листах; шесть крошечных соединителей сохранены локально. Актуальные референсы и контракт находятся в `reference/ride_parts_normalized/`. Сервисы и декор добавляют 44 уникальные детали на трёх листах `reference/scenery_parts_normalized/`: точные зеркальные повторы восстанавливаются бесплатно.

Ещё 20 уникальных деталей одного листа `reference/extras_parts_normalized/` обновляют скамейку, входные арки и флаги, каменные и цветочные бордюры, створки и стрелки. Два зеркальных варианта восстановлены локально. Кассы и дым улучшены локально без API.

Персонажи в `reference/actors_full/` содержат 224 части: восемь гостей по 25 поз/голов и 24 фазы ходьбы охранника/механика. Неиспользуемые пустые фазы повара не генерируются. Контракт сохраняет исходные размеры, смещения и имена ресурсов. Генерация выполняется в 2K, фон меню — в 4K; исходный результат модели сохраняется целиком без уменьшения разрешения.

Все 224 части установлены; финальная QA не содержит предупреждений. `actor_selections.json` выбирает принятый вариант последнего листа и проверяет его SHA-256. Неверные направления, случайная борода из стилевого эталона, смещённые границы рядов и пропадающий чемодан исправлены локальными кропами, зеркалами и повторным использованием правильных поз. Эти исправления воспроизводятся установщиком и перечислены в `review/actors/report.json`.

```sh
python original/export_part_atlases.py --normalized
python original/export_part_atlases.py --scenery --normalized
python original/export_actor_full_atlases.py
python art/fix_alpha.py
python art/install_parts.py --install
python art/install_actors.py --install
```

Установка сохраняет оригинальную геометрию и якоря. В игре аттракционы собираются из HD-деталей по исходным командам, что не требует загружать тысячи огромных готовых текстур. Полные собранные кадры, контактные листы, GIF-проверки и отчёты остаются в `art/review/`, за пределами APK. Проверенные исключения принимаются через `accepted_qa` с проверкой хэшей, без общего пропуска предупреждений. Ordinary sprite overrides находятся в `game/assets/hd/manifest.json`; установщики сохраняют чужие записи.

У Riverflow обнаружены несколько ошибок маски прозрачности: RGB содержит камни/воду, но alpha полностью либо частично обнулена. `fix_alpha.py` восстанавливает только проверенные ячейки по цветности и малым внутренним бликам в `art/corrected/`, не меняя `raw/`. Неверные задние ракурсы NPC исправляются локальным отражением уже проверенной противоположной фазы; все такие изменения перечислены в отчёте установки. Новых API-запросов для этих исправлений нет.

Портретное меню установлено как `game/assets/hd/ui/menu_portrait.png` (2304×4096) и `menu_portrait_hd.png` (1080×1920). Альбомный фон сохранён для других экранов. Оригинальный bitmap-шрифт используется в заголовке меню; основной интерфейс — читаемым шрифтом Godot с кириллицей. Текст рисуется отдельно, фоновые картинки текста не содержат.
