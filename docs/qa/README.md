# Проверка релиза 1.0.0

Среда: Linux, Godot 4.7.2, RTX 3070 Ti; Android Emulator 37.2.12,
Pixel 7 / Android 15 API 35 / 1080×2400 / 3 ГиБ RAM. APK ARM64 запускается
через ARM-трансляцию Google APIs x86_64. Android использует OpenGL ES 3.1;
настольный рендер сравнения памяти — Vulkan.

Разница между профилями ремейка — около **42%**. Это память текстур текущего
настольного процесса; не полная RAM приложения, не результат на телефоне.
Для продолжения анимации после победы benchmark явно включает тестовый режим;
его служебные кадры не используются в рекламной галерее.

## Сборка из Git

Финальная APK собрана из чистого клона коммита `eda8072`, без `.godot/`
и игнорируемых ресурсов рабочей копии. Полный `tools/build_apk.sh` прошёл успешно.
Отдельно проверены все 89 символов и встроенные атласы обоих bitmap-шрифтов.
На чистом импорте Godot [встраивает страницы шрифта и помечает PNG как skip](https://github.com/godotengine/godot/blob/4.7/editor/import/resource_importer_bmfont.cpp);
проверка APK учитывает этот формат упаковки.

## Архив APK

Проверены CRC, подпись, ориентация portrait, отсутствие INTERNET,
исключение тестовых исходников, 1179 отдельных текстур мира и 2 встроенных bitmap-шрифта, 153 превью,
224 части персонажей HD и лицензия шрифтов. Итоговые размер и SHA-256 — в `apk.json`.

Godot/aapt2 выводит предупреждение о неиспользуемой записи `themed_icon.xml`.
Реально установленный `icon.xml` и три слоя адаптивной иконки присутствуют и проверены.
При запуске эмулятора Vulkan недоступен; после диагностического сообщения
движок успешно переключается на GLES. Эти предупреждения не скрывались.

На хосте один раз завершился сам процесс эмулятора с SIGSEGV после часа
повторных установок и переключений графики. Эмулятор перезапущен, сохранение
восстановилось, итоговая APK повторно проверена. Для проверки экранной клавиатуры
отключён виртуальный PS/2-драйвер эмулятора; [кадр с клавиатурой](android-search-keyboard.png).

Физический телефон для этой сессии не использовался. Длительный нагрев,
автономность и FPS на конкретном телефоне ещё требуют отдельного плейтеста.
