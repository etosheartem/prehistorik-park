# Звук первой версии

В оригинале один звуковой файл: `original/jar/sound/entry.mid`. Диалогов и речевых файлов нет. Поэтому озвучка через API для восстановления оригинала не требуется.

## Готовые ресурсы

- `game/assets/audio/entry.ogg`: исходная композиция, 65,18 секунды, 44,1 кГц, стерео. Ноты, темп и MIDI-программы сохранены. Рендер выполнен локально установленным OpenJDK/Gervill; звучание его процедурного General MIDI-банка отличается от синтезатора старого телефона. Громкость приведена к −20 LUFS, хвост плавно затихает для спокойного повторения.
- Семь коротких эффектов `click`, `build`, `demolish`, `coin`, `error`, `notification`, `success`: локальный детерминированный синтез дерева, камня и колокольчиков. Это дополнение новой версии, а не звуки, извлечённые из JAR.
- `manifest.json`: происхождение, хеши, длительности, пиковые уровни, подтверждение отсутствия обращений к платным API.

Суммарный размер музыкального файла около 1 МБ. Никакие SoundFont-пакеты не загружались. Расход OpenRouter: **$0**.

## Подключение

`park_audio.gd` — узел с интерфейсом `configure({music: 0..1, effects: 0..1})`, `effect(name)`, `suspend(bool)`, `shutdown()`. Отдельно регулируются музыка и эффекты. Поддерживаются также ключи `music_volume` и `effects_volume`.

Музыка запускается при добавлении узла в сцену и повторяется. Системная приостановка сохраняет позицию музыки и останавливает короткие эффекты. Пул ограничен шестью звуками; одинаковые события чаще 65 мс объединяются, чтобы прокладка дороги не создавала громкий треск. `shutdown()` окончательно останавливает воспроизведение.

Для стройки вызывается `build`/`place`, сноса — `demolish`/`remove`/`delete`, найма — `coin`/`hire`, недоступного действия — `error`, предупреждения — `notification`/`warning`, победы — `success`/`win`. Обычные кнопки используют `click`, `select`, `confirm`, `cancel` или `rotate`.

## Воспроизведение и проверка

```sh
python original/export_audio.py
python original/export_audio.py --check
godot --headless --path game --script res://tests/audio_check.gd
```

Экспорт требует установленные JDK и FFmpeg, подключение к сети не требуется. Исходный MIDI и промежуточный WAV сохранены. Проверка хешей не пересинтезирует музыку; тембры могут зависеть от версии JDK. Проверка Godot покрывает громкости, приглушение, паузу/возобновление, ограничение пула, повторение музыки и завершение работы. Финальный баланс громкостей всё ещё следует послушать на телефоне.
